# __Contact Manager__
Application PHP en ligne de commande permettant de :

- lister les contacts
- afficher le détail d'un contact
- créer un contact
- supprimer un contact

## __Installation__
Voici les instructions pour installer le projet PHP :

- Créez la base de données en important le fichier contact_manager.sql fourni. Ce fichier contient les instructions SQL pour créer les tables et insérer quelques données fictives dans la base de données.

- Copiez le fichier config.example.php et appelez le nouveau config.php, et mettez le à jour avec les identifiants de connexion à la base de données. Vous devez remplacer les valeurs par défaut pour le nom d'utilisateur, le mot de passe et le nom de la base de données par les valeurs appropriées pour votre environnement.
## __Lancement__
- Pour exécuter ce projet, ouvrez un terminal à la racine du projet et exécutez la commande suivante :

```
php main.php
```
